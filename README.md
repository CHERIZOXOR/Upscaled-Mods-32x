<h1 align=center>Upscaled Mods 32x</h1>
<p>A small add-on for <a href="https://modrinth.com/resourcepack/faithful-32x">Faithful 32x</a> that adds stylistically consistent textures for several mods. Originally, the plan was to include this in <a href="https://github.com/Faithful-Resource-Pack/Faithful-32x-Mods">Faithful 32x Mods</a> itself, but since the authors rarely check GitHub, I decided to package my specific changes into a separate add-on.</p>
<h2 align=center>Mods Support</h2>
<ul>
  <li><a href="https://modrinth.com/mod/appleskin">Apple Skin</a> (Based on Faithful 32x Mods, but I changed the item tooltip icons to ones that are less flat.)</li>
  <li><a href="https://modrinth.com/mod/better-advancements">Better Advancements</a></li>
  <li><a href="https://modrinth.com/mod/cloth-config">Cloth Config</a> (based on Faithful 32x Mods, but I changed gui to ones that are less flat.)</li>
  <li><a href="https://modrinth.com/mod/enchanting-infuser">Enchanting Infuser</a> (currently partial)</li>
  <li><a href="https://modrinth.com/mod/jade">Jade</a></li>
  <li><a href="https://modrinth.com/mod/jei">JEI</a></li>
  <li><a href="https://modrinth.com/mod/jrftl">JRFTL</a></li>
</ul>
